# v0.4.4.1 使用说明

本页使用已保存的历史行情。资料过期时，仍不能判断今天的买卖点，也不会开放实时交易资格。

1. 选择证券。需要回看某一天时，展开「调整分析因子」，将数据模式切到「历史回放」，选择纽约交易日期。
2. 在主图上选择「显示当前实验EMA」或「对比原始EMA与实验EMA」。青色为短期，橙色为长期；原始参数是半透明虚线，实验参数是实线。图例里的数字就是当前周期。
3. 展开「调整分析因子」，拖动 EMA 滑块。主图和比较表会自动重算；可点「查看同步更新的主图」回到图表。ATR、横盘阈值和候选距离的效果继续在比较表中查看。
4. 因子区顶部「当前生效」才代表实际使用的参数。下拉框只是准备载入的组合，选中后还要点「载入组合」。修改任一滑块后会显示「自定义参数（未保存）」。切换证券、日期会保留当前参数。
5. 输入名称并点「保存组合」，成功提示包含名称和版本。刷新后可从列表选择并载入；五个滑块会恢复保存值。旧版 v0.4.4 的组合仍可载入。
6. 点「恢复默认」，五个参数、状态、图表和比较表一起恢复 Baseline。Baseline 不能被覆盖。页面刷新后从 Baseline 开始，保存的组合需明确载入。

「叠加用户计划价格」独立控制原有计划线，与 EMA 图层无关。「重点观察的5只证券」按固定顺序显示，不是今日最佳交易排名；每张卡显示自己的资料日期，点「查看图表」切换证券。

指标按每个时点最近50根合格且已完成K线计算，前49根不画EMA；若当前资料不足或来源不合格，会显示原因。历史回放不会画截止时点之后的K线。实验结果仅供历史观察，不代表实时信号。

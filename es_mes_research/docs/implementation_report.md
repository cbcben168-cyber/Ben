# ES/MES 独立研究实施报告

日期：2026-10-04（Asia/Shanghai）。结论：**研究工具和可选开关已实现，真实数据获取被Futu权限阻塞；没有真实回测结果。**

## 选择方式

默认关闭，没有自动开启ES或MES。scripts/choose.ps1提供0关闭/1 ES/2 MES/3两者，CLI也可选择。选择只存本项目state/selection.json，不启动任务，不替换SPY，不下单。状态显示数据、费用与权限；切换产品不删除研究记录。

## 实际数据证据

2026-10-04 02:25 UTC左右读取Futu美国期货目录成功，ES实际合约21个、MES实际合约5个。US.ES2612与US.MES2612报价均返回FUTURES_PERMISSION_DENIED，对最近完成的现金交易日1m历史请求也均返回同样权限拒绝。目录可见不等于可取数据；没有购买订阅、尝试绕过权限或访问交易账户。

因此本项目没有ES/MES真实分钟缓存、收益、KEEP或未来forward结果。临时测试数据只在pytest临时目录，用来验证逻辑，绝未当作行情或盈利产物。

## 实现范围

- 独立es_mes_research目录、Python模块、README、运行说明、菜单与默认关闭开关；独立codex/es-mes-research分支，基于远程默认分支，独立PR；SPY PR不掺入期货改动。
- Futu quote-only权限probe与有限历史分页；拒绝主连别名和无进展分页，权限拒绝不反复重试。可导入真实UTC起始分钟CSV与明确换月映射。
- 完整现金RTH、DST/半日市、唯一分钟、OHLC/volume、0.25价格tick、实际合约、到期日和因果换月检查。夜间/CME全时段日历未实现。
- 固定ORB10 + 3R，首个10:30前收盘突破、下一5m开盘、一天一笔、向外tick取整止损、实际含滑点入场R。1m保守退出与目标穿过一tick才计填单，跳空和收盘按实际规则。
- ES每点50/MES每点5，费用为每合约往返美元和市场成交滑点tick。默认不填手续费，拒绝无成本回测；不沿用SPY 2bps。
- 输入/source/manifest hash及拒绝覆盖；至少500完整日后按60/20/20和边界一日embargo，仅运行Train。CSV/MD/JSON、美元PnL/净R/季度/日终回撤、明确换月持有基准和等待用户选择CSV。
- 没有matched controls/bootstrap、独立确认、保证金模型、实时forward、每日收盘调度或自动优化；formal_data_gate=false，不能KEEP。

## 验证

21项项目测试通过，原仓库142项测试通过；合并测试目标共163项。包含默认关闭、选择互斥、两合约乘数、费用滑点、长短3R、tick取整、目标触及不假设填单、止损冲突、跳空、10:30截止、美元回撤、缺失/重复/非法/时区/主连拒绝、DST半日、换月前视、注册不可覆盖、manifest篡改、权限不重试与费用缺失。

菜单PowerShell解析错误0，实际status为selected=[]、两个dataset=false、fees未配置；实际probe记录权限拒绝。兼容性弃用警告保留，不声称无警告。无全局安装/配置、订单、后台常驻、部署或PR合并。

## 下一步由用户选择

可以保持关闭。想使用时：选择ES/MES；核实Futu OpenAPI相应行情/历史权限，或导入合格真实数据；明确成本假设；检查时区/合约/换月来源；足够数据后运行固定Train测试。订阅购买、账户权限改变和其他高影响操作不在本轮授权中，不会自动办理。

ES/MES相同指数的两个市场不能当两次独立edge证据。导入/费用中的声明需要进一步核验；完成软件不等于已发现可盈利策略。

# UI V2 变更记录

## 首页改造
新增 desk/workspace.py 响应式工作台，保留既有行情适配器和 ICT 计算。首页技术大卡改为简洁状态提示与可展开诊断；增加候选选择、周期与图层控制、保守决策卡、按标的保存备注和事件已读持久化。持仓明确标记未连接交易记录。
冻结规格原文件 UI_LAYOUT_V2_REDOWNLOAD.md 保持不变。

## 简体中文本地化
新增 desk/i18n.py 集中文案与展示转换函数。菜单、决策、方向、阶段、提醒、诊断和异常状态默认中文。数据库原字段与保存内容、Futu 行情接口、ICT 计算和策略参数保持不变。
正文档案和启动说明使用简体中文；技术代码保留时提供中文解释。用户输入原文不作翻译。

当前仍为 PARTIAL（部分完成），双屏验收为 PENDING_VISUAL_ACCEPTANCE（等待视觉验收）。未完成功能与回滚说明见 UI_V2_ACCEPTANCE.md。


## 核心功能补齐
新增完整前周RTH日历周价格、四组图层、版本化人工计划与保守风险回报、关联提醒；定时刷新与编辑隔离。修复网格包装层定位、跨周期选股回退和数据库连接释放。22项自动测试通过；浏览器截图和互动证据见UI_V2_ACCEPTANCE.md。总体仍部分完成，Windows原生缩放仍待确认。


## 稳定性专项修复
修复多窗口刷新键竞争、空返回覆盖有效历史图表、重复聚合及订阅；加入故障隔离、受限恢复、运行心跳与指纹。真实15分钟／1小时数据和浏览器已核对。31项测试通过；旧服务退出原因和长期稳定性仍待裁定。详见STABILITY_ACCEPTANCE.md。

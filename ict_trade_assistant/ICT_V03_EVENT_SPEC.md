## 输入资格与时间

- 仅接受有时区、来源、OHLCV、RTH标识、分钟完整资格的分钟数据；按 `America/New_York` 和XNYS日历核对。拒绝重复时间、非有限数、错误OHLCV、分钟网格偏移及未知来源。
- 先剔除评估时点之后的分钟。即使缓存eligible为真，分钟收盘加2分钟隔离未结束仍不可用于确认。
- RTH从09:30锚定1H，正常日6根60分钟加1根30分钟尾柱，尾柱不是额外完整60分钟。每桶必须分钟数、时间集合均完整。缺桶会切断结构上下文并关闭活动链，不能跨缺口拼三根FVG或Pivot。
- 前日水平仅取上一个真实交易日完整390分钟的高低点；前日或当日为提前收盘日时不产生新Sweep链。不用前周点位替代前日点位。
- `occurred_at` 为确认K线名义收盘时间；`confirmed_at` 为收盘加2分钟的工程可知边界。形成中事件的发生时间不晚于当前评估时点，`bar_end` 单独保存预期收盘。Pivot同时保存中心柱时间与右2柱完成后的 `known_at`。
- 上述时间是历史数据按当前规则计算的确认边界，不能证明供应商当时已交付数据。统一保留 `VENDOR_FINALITY_UNVERIFIED`，不宣称历史PIT资格或真实盘中接收时间已验证。

## 事件定义与价格

| 事件 | 触发与确认 | 失效／降级 |
|---|---|---|
| Sweep/Reclaim多向 | 同根完整1H low严格小于PDL，close严格大于PDL | 越过但收盘未严格收回：该候选INVALIDATED；未完成桶只能FORMING |
| Sweep/Reclaim空向 | 同根完整1H high严格大于PDH，close严格小于PDH | 同上；同柱双向扫荡并收回为歧义，拒绝进入链 |
| MSS | 严格Pivot左2右2。Sweep确认时固定最近、事前可知的方向Swing；之后4根内收盘严格越过结构价 | 无已知Pivot不补造；不允许用Sweep之后才确认的Pivot替换；超时关闭 |
| FVG | 三根连续完整柱：多向第三根low>第一根high且中间柱阳线；空向第三根high<第一根low且中间柱阴线 | 相等边界不构成缺口；第三根未完成不得确认 |
| CE | FVG上下界算术平均。只在形成柱之后的完整柱检查区间是否覆盖CE | 形成柱不算回踩；6根后超时；不是限价成交或入场建议 |

FVG独立识别，不要求一定已有Sweep/MSS；未关联完整链的缺口只显示为独立历史缺口。完整链只采用MSS当根起6根内同方向FVG。每个方向缺口记录 `NEW → WAITING_RETEST → TOUCHED` 或 `INVALIDATED`，已触及状态不回退；完整柱收盘越过远端边界或期限结束即失效。

Sweep失效价为扫荡极值加／减确认前14根完整柱TR均值的10%缓冲；缺14根TR时仍记录已识别Sweep，但关闭该链并解释失效价不可计算，不凭空给风险价格。失效价触及与CE同柱时优先失效；不推断柱内先后、盘口成交或盈亏。

## 状态机与审计

`WATCH → SWEEP → MSS → FVG → CE_REVIEW → INVALIDATED`

任一活动阶段均可因数据缺失、Sweep失效价、FVG远端收盘、期限结束或新交易日首个Sweep取代而进入INVALIDATED。每个正常交易日仅使用首个合资格已收回Sweep，后续信号不替换首个机会；双向歧义消耗该日机会。未收回的候选独立记录为拒绝，不冒充已确认链。

每条状态记录：确定性事件ID、观察链ID、类型、方向、状态、流动性／结构／缺口价格、发生时间、确认时间、来源、触发条件、证据K线、策略版本、参数版本及失效原因。Sweep附水平已知时间、极值、ATR；MSS附Sweep ID、固定结构价、Pivot已知时间及5根证据；FVG附三根证据和上下界／CE。

参数常量集中于 `desk/ict_v03.py:PARAMETERS`，参数版本来自规范JSON的SHA256前16位；没有参数寻优。相同输入与as-of时点得到相同事件ID与结果。历史计算不写用户事件表，不产生实时提醒；离线验收脚本另存完整JSON／CSV，重复运行覆盖同一验收文件，不追加伪提醒。

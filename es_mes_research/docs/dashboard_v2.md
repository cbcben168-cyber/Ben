# ES/MES 交易驾驶台 v2

FastAPI 提供接口，Vue 提供本地网页。只监听 `127.0.0.1:8765`，保留原 Forward 模拟观察规则与数据资格门槛，无券商交易接口。

## 日常使用

1. 运行 `scripts/dashboard.ps1`，打开 http://127.0.0.1:8765 。独立 `.venv` 已安装项目依赖；旧版启动器需要替换为输出目录的新版启动器。
2. 在“数据与连接”检查 OpenD 报价快照和历史一分钟权限。权限记录的检查时间可见；开通期货账户不自动证明行情权限可用。
3. 在“运行设置”填写实际合约、到期日、接口时区、往返费用和单边滑点。启动之后冻结这些参数。时区/到期日仍需资格核验，不推断真实交易费用。
4. 首页查看完成的 1m/5m K 线、OR 高低线、MA9/20/50、信号、模拟入场与平仓标记。点击买卖点或交易行展开详情。五分钟视图不显示未完成五分钟柱；均线按选中的 K 线周期计算。
5. “交易数据”查看数量、方向、入场/出场、止损/目标、费用、滑点、净盈亏及状态。可选历史交易日，下载交易 CSV、事件 JSONL、完成分钟 CSV 和收盘 MD 总结。
6. “研究与优化”查看收盘建议，并选择保持冻结、核验数据及费用、独立研究入场延迟。选择与被复盘的交易日关联并持久保存，不会自动修改冻结规则。

## 更新与数据含义

页面通过 SSE 每秒接收一次状态，行情采集仍约每三秒一次，不把页面刷新当作行情更新。价格、报价时间、接收时间与报价年龄分别可见。页面断开时保留最后数据并标注中断；浏览器本地继续计算年龄，停止浮盈估值。报价超过十秒、未来时间或尚无报价时不估值。历史日期不显示当前持仓。

绿色模拟入场、红色模拟平仓、蓝色突破信号分别标注；突破信号使用已完成五分钟收盘价，旧日志缺少收盘字段时只标区间线并明确说明。模拟成交采用新鲜 last quote 加声明滑点，不能称为实际券商成交或精确下一根开盘成交。已实现净盈亏来自 EXIT_PROXY 记录，数据无效的观察不计入收益；未发生有效交易时显示“—”，不以零收益伪装策略表现。浮盈为未扣费用的价格浮盈，已实现净盈亏已扣声明费用。

已有历史文件保持原样。仅新增事件元数据（品种、合约、数量、费用、滑点、执行方式），不回填旧日志缺失字段。历史研究 core.py 与已注册结果不修改；forward.py 的新增展示元数据和信号收盘字段会反映在下一次运行源代码哈希中。

## 工程与验证

- `src/es_mes/dashboard.py`：FastAPI 应用工厂、Pydantic 输入校验、SSE、下载与 Host/Origin/CSRF 防护；关闭服务通知观察线程停止。
- `src/es_mes/dashboard_data.py`：只读数据投影、交易对账、报价年龄、有效收益、历史日期、选择记录。
- `frontend/`：Vue runtime 渲染、独立 SVG 图表、响应式样式、锁定的 npm 依赖；不依赖 CDN，不使用动态模板求值。
- `src/es_mes/web/`：可随 Python 包分发的本地构建资源，保留 Vue MIT 许可。执行 `cd frontend; npm ci --ignore-scripts; npm run build` 可重建。
- Python：`./.venv/Scripts/python.exe -m pip install -e '.[dev]'`；直接运行 `./.venv/Scripts/python.exe -m es_mes.dashboard`。
- 检查：`./.venv/Scripts/python.exe -m pytest tests -q`；前端 `npm test`；`pip check`、`npm audit --omit=dev`、`git diff --check`。

验证覆盖：价格/成交记录/标记一致、5m OHLCV 聚合、未完成柱隐藏、陈旧浮盈、无效收益排除、CSV导出、跨日选择保存、非法日期/路径、跨来源写入拒绝、未知操作拒绝、SSE新状态推送。测试夹具仅在临时目录使用，不写入真实数据或网页生产记录。

没有设置开机启动或计划任务。电脑和 OpenD 必须在线；关闭服务会中断观察，未完成持仓依然触发恢复阻塞。当前账户是否具备行情权限应以最新检查为准。本次网页升级未产生真实交易、回测收益或 KEEP 结论。

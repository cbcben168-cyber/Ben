## 故障与修复

8506的旧启动脚本只设置 `ICT_V04_HISTORY`、`ICT_V04_DB`。独立Futu日K库、版本目录及1H档案依赖临时环境变量，重启后没有恢复，页面回到截至2026-10-29的原始历史档案。原来的顶部文案又将历史分析与实时执行资格混为一个“继续等待”状态。

现在由 `data/history-runtime.json` 明确保存历史数据、用户数据库、实验数据库、Futu日K基准、版本目录及可选1H目录。路径相对配置文件解析；不扫描或猜测其他目录，不保存密钥。启动器和直接历史入口都执行相同配置检查，持久配置覆盖旧环境变量。缺少配置、日K、用户库或有效版本指针时明确停止，不自动退回基准或旧档案。可选1H目录缺失仍允许独立日K分析，具体原因由现有1H读取器显示。

启动器核对健康响应、运行身份及配置指纹，已运行但配置不同的实例会被拒绝复用；不自动停止或重启它。健康检测也覆盖Windows TCP枚举没有返回监听记录的情况，避免重复启动。顶部明确区分历史趋势、历史资料状态、所选周期截止时间和实时交易资格；过期历史仍可看到截止时点的趋势，并明确不能用来判断当前行情。

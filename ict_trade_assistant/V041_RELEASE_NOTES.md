# v0.4.1 动态观察名单本地交付

日期：2026-11-03。基线为本地v0.4提交`5cee6e2`及未合并草稿PR #40。本轮按用户批准部署至8506，不修改冻结策略或实时资格。

## 使用

打开 http://127.0.0.1:8506 。双击入口仍为同目录`Start_ICT_Desk.cmd`。

展开左侧导航，进入“设置与审计 → 观察名单管理”。输入SMH或US.AAPL，填写分组后添加；用搜索或分组筛选找到证券，在“管理证券”中选择代码，勾选/取消“启用此证券”并保存，或点击“从观察名单删除”。删除不删除人工计划、备注和历史证据。名单没有20只总量限制。所有变更落在原v0.4独立数据库`data/v04/desk.sqlite3`，不写v0.3数据库。

“导入美国ETF AUM Top20预设”可重复点击，仅添加缺项；保留已有用户证券、分组及启停状态。预设来源为用户指定固定名单，登记日期2026-11-03，排序口径为美国ETF AUM，原始AUM统计日期未提供，未经实时排名核验。元数据及给定顺序均保存，不把工作台候选优先级当作AUM排序。

工作台中点击候选卡，或展开“设置与数据诊断 → 独立窗口观察标的”切换证券。候选卡切换后会同步更新该选择框。底部“备注与人工计划编辑”的编辑标的独立，保存前核对计划标的。停用/删除证券不参与数据加载和候选排名，已存在计划仍可维护。

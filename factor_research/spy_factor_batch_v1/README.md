# C1 六因子批量回测 V1

可直接复制到富途量化的完整文件：

`SPY_SIX_FACTOR_BATCH_V1.py`

长期TRAIN使用独立文件：

`SPY_SIX_FACTOR_BATCH_TRAIN_V1.py`

完整中文参数和验收步骤见 `C1_TRAIN_RUNBOOK.md`。TRAIN系统起点为2025/07/01，正式统计仍严格从2025/10/01开始；富途界面使用已实测的1分钟行情驱动，代码读取已完成5分钟K线 `select=2`。

该文件一次读取每根已完成的 SPY 5 分钟 K 线，同时计算冻结的 F001–F006，并在未来第 3、6、12 根 K 线完成后输出一条紧凑事件。它不访问账户、持仓或订单接口，不读取 Volume，也不把 close-to-close 未来收益解释为成交利润。

## S0 功能回归参数

- 唯一驱动资产：`US.SPY`
- 历史回测日期：`2026/09/28`–`2026/10/06`
- 周期：5 分钟，RTH，行情驱动循环
- 不使用“每天指定时刻运行一次”
- 复权设置必须与 F001 功能回归保持一致并人工记录
- 回测完成后导出完整 `RunLog_*.csv` 到看板监控目录

正常完整交易日应输出 65 条 `FACTOR_EVENT`，时间从 09:35 到 14:55 ET；最后一条事件的 60 分钟标签在 15:55 ET 成熟。S0 只验证合同、时序、六因子计算和 F001 口径，不用于发现 Edge。

## 冻结因子

| ID | 定义 |
|---|---|
| F001 | `C[0] > EMA20[0]` |
| F002 | `EMA20[0] > EMA20[3]` |
| F003 | `C[-1] <= EMA20[-1] and C[0] > EMA20[0]` |
| F004 | `C[0] > max(H[-1],...,H[-5])`，不含当前 K 线 |
| F005 | `C[-2] < C[-1] < C[0]` |
| F006 | `C[0] > O[0]` 且实体/振幅 `> 0.60`；零振幅为无效测量 |

逻辑 `[0]` 对应富途 `select=2` 的最新已完成 K 线；历史引用据此增加 select。实际平台通过必须以富途导出的 S0 CSV 为证，本地测试不能代替平台兼容性验收。

完整字段合同见 `BATCH_CSV_CONTRACT.md`。

# v0.4 SOP下一条件规范

输出字段：当前阶段、事件ID、发生与确认时间、来源与原始证据、下一条件、下一观察区域、观察期限、已知失效价／条件、缺项、允许及禁止动作。

|阶段|下一确认条件|人工边界|
|---|---|---|
|PRICE_WATCH|完整1H越过流动性水平并收盘收回|核对价位与分钟完整性|
|SWEEP_CONFIRMED|收盘严格突破Sweep确认时已知且固定的Pivot|缺Pivot时不代入未来Pivot|
|MSS_CONFIRMED|同链同方向关联FVG|不拼接独立缺口|
|FVG_CONFIRMED|形成柱之后完整K线触及CE|独立FVG先补合格Sweep/MSS关联|
|CE_REVIEW|人工审查风险、价格、数据时效及执行|不是自动入场确认|
|INVALIDATED|关闭旧链，等待新条件|保留原证据与失效原因|
|UNKNOWN|补齐数据资格、来源及完整证据|不推进结构阶段|

1H确认必须收盘并隔离2分钟。缺分钟、异常OHLCV、未完成K线、时区错误等沿用冻结识别器阻断。4H/D保持UNKNOWN。历史结构事件可以保留展示，当前无合格价格或ATR时SOP阶段为UNKNOWN，另留historical_stage便于追溯。

允许记录备注和维护人工计划；只有合格LIVE且完整链达到CE_REVIEW才列出人工风险与执行审查。任何阶段都禁止自动确认入场、自动下单数量、账户／持仓隐私查询、订单调用和ICT实时自动提醒。

人工计划原有证券、价格、失效、目标、备注保持；新增人工证据补充、可选决策证据快照。只有用户勾选才将当前快照附加到计划版本；旧版本不改写。多窗口使用原有expected_version事务检查阻止旧版本覆盖；编辑器在行情片段外，未提交输入不随行情片段刷新。硬刷新／关闭浏览器仍需先保存表单。

基础价格提醒沿用原LIVE价格健康门禁；闭市与STALE只作历史准备。提醒身份含证券、事件／计划ID、状态、日期和版本，由既有事务和唯一键去重。ICT历史决策不写入实时提醒；实时ICT开关禁用。复盘仅保留计划与证据历史，本阶段不导入成交，v0.5另行处理。

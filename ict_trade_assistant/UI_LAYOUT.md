# UI Layout v0.1

深蓝简洁工作台，中文主界面，状态文字与颜色共同表达，宽屏主图。

侧栏：品牌、导航（交易工作台 / 事件与备注 / 设置与审计 / SOP 与进度 / 其他策略 / 交易记录 / 期权），观察标的与手动刷新。

工作台：ET 时钟与 Session → 数据健康卡（来源、权限、行情时间、接收时间、延迟）→ 标的 / 周期 / 日期 → Plotly 蜡烛图与关键价图层 → OR 与关键价可复核表 → 观察状态、区域与失效原因 → 原始数据与完整性展开区。

事件页：最新提醒表、原因、价格、区域、时间、Session；人工备注输入与历史记录。

设置页：名单增删；提醒距离（基点）、刷新秒数、图层；标的区域上下限、方向、失效价、人工 SOP 阶段；所有保存动作写入审计。OpenD 仅允许本机 127.0.0.1:11111。

SOP 页：先确认数据健康 → 核对 RTH/PRE/NIGHT → 复核关键价和 OR 完整性 → 手工记录 Sweep/MSS/FVG → 区域观察 → 记录失效。明确无自动形态确认、无订单功能。

预留页：统一显示 NOT IMPLEMENTED，说明未实现能力，不展示虚构统计。

# ES/MES 网页与实时诊断

在项目目录运行 `./scripts/dashboard.ps1`，打开 http://127.0.0.1:8765 。只监听本机，不安装服务、不设置开机启动、不改执行策略。关闭程序就停止观察；已有模拟持仓若未结束，下次进入恢复阻塞状态，不能冒充完成成交。

网页操作：重新检查行情权限；填写 ES/MES、实际合约、到期日、接口时区、每合约往返费用、单边滑点；启动；暂停新入场；继续；下载每日总结；记录优化选择。检查权限距启动不超过十分钟，快照和历史分钟数据都必须可用。当前账号 2026-10-04 检查仍返回 FUTURES_PERMISSION_DENIED。期货交易权限与 CME 行情权限分别检查。

策略保持 10-Min ORB + 3R。只在 XNYS 美股现金时段建立区间及交易，不是夜盘策略。下一根开盘的精确成交在订阅确认延迟下无法保证，所以独立注册为 `DIAGNOSTIC_LIVE_QUOTE_PROXY`：完成五分钟信号确认后，十秒内新鲜 last quote 加声明滑点入场，3R 根据实际代理入场计算；不是 broker fill、不是精确下一根开盘，不能与历史开盘成交混为一组。报价代理止损使用首次观察到的越界报价加滑点，目标要求超过一 tick；每品种单次运行选择一个真实合约、一合约、每日最多一笔。

一分钟前缀必须从现金开盘连续，OHLC、成交量、tick、重复及分钟对齐检查通过。开盘十分钟后首次启动不补交易；信号迟到、暂停及数据异常跳过首个信号，不尝试第二次。数据请求有限重试，权限失败立即阻塞；陈旧/未来报价拒绝；价格观察间隔超过十秒时已有代理持仓标记无效，不用缺失期间价格计算有效PnL。日期切换存在未完成持仓则停止。进程中断后的未完成观察必须人工检查检查点与日志，当前没有自动填补恢复功能。重新启动保留已处理信号，避免同日重复交易。

`state/forward_checkpoint.json` 为原子写检查点；`artifacts/forward/YYYY-MM-DD/events.jsonl` 为按纽约日期追加的审计事件；收盘后输出 observations.csv、report.md、optimization_choices.csv。费用、时区、到期日为用户声明，formal_data_gate 始终 false；先核验期货实际时间语义再升级研究资格。此版不宣称KEEP，不修改原历史研究或锁定样本。

每日优化选项：KEEP_FROZEN、QUALIFY_DATA_AND_COSTS、REGISTER_ENTRY_STUDY。网页选择只追加 USER_OPTIMIZATION_CHOICE 事件，不修改策略、不跑自动搜索；后续实现新假设需独立注册版本并按批准范围实施。单日盈亏不足以指导TP/SL优化。

安全：localhost绑定；Host、Origin、随机CSRF token检查；有限体积JSON；命令白名单；不接受任意路径或shell命令；无账户、订单、交易上下文。网页日志不包含密码/密钥。运行账户仍应保管好本机访问权。

验证：`PYTHONPATH=src python -m pytest tests -q`；仓库回归加根 tests。测试覆盖区间、下一段报价、实际手续费滑点、单日上限、缺口、陈旧报价、迟到、暂停、恢复阻塞、本机HTTP写保护。测试夹具是合成数据，仅用于测试；没有真实收益报告。运行时须保持电脑与OpenD在线，不能把网页打开视为行情通过或已经开始交易。

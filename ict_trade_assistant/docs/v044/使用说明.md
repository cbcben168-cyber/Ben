# v0.4.4 使用说明

1. 打开工作台，在顶部选择证券，例如 **US.SPY**。
2. 展开主图和 Top5 下方的 **调整分析因子**。
3. 选择 **最新已保存数据**，或选择 **历史回放** 和一个已有归档交易日。日期按纽约时区处理，截止到该交易日收盘后两分钟。
4. 拉动滑块，数值和分析自动更新。无需提交，也无需修改代码。
5. 查看“原始参数与实验参数对比”：趋势、波动、候选距离资格、计算数值和变化量。分类没有改变时会明确说明。
6. 输入名称，点击 **保存组合**。以后选择该参数组合，再点击 **载入组合**。点击 **恢复默认** 回到原始数值。固定的 Baseline 不能覆盖。

| 因子 | 默认 | 可调范围 |
| --- | --- | --- |
| EMA短期周期 | 20 | 5–30 |
| EMA长期周期 | 50 | 35–50 |
| ATR计算周期 | 14 | 7–20 |
| 横盘EMA距离阈值 | 0.50 ATR | 0.10–1.50 ATR |
| 候选关键价距离 | 0.25 ATR | 0.05–1.00 ATR |

至少需要50根连续、同源、已完成的K线。资料不足时，先读页面说明；不会补造缺失行情。只有日K的证券可以分析日线环境，但不能取得1小时ICT资格。

每只证券独立显示数据时间。Top5为固定观察顺序，不能当作当前市场排名。实验组合只影响历史分析，不修改人工计划、观察名单或正式候选设置；实时行情尚未通过验收。

部署前的隔离验收入口为8520；8506替换需单独批准。

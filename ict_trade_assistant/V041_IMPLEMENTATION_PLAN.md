# v0.4.1 实施与验收计划

设计依据：用户2026-11-03批准的动态名单、完整观察工作流与有界历史加载范围。

1. `desk/watchlist.py`提供规范化、默认四ETF、用户指定Top20及来源元数据；`desk/store.py`在当前独立库settings中事务保存注册名单，不迁移v0.3数据库。UI支持搜索、单组归类、启停及删除；原计划不随删除消失。
2. `desk/watchlist_ui.py`嵌入设置与审计，替换原20条限制的文本框。Top20导入仅添加缺项，保留已有组别及启停；当前22只（含IWM/SOXX）不代表实时AUM排名。
3. `observations/decision/workspace`增加可选动态证券池参数，默认四ETF常量不变。启用池参与排名；停用证券可查计划但不加载排名。VIX仅背景。缺数据不产生合格focus或ICT信号。
4. 本地历史入口改为按标的转换/缓存已有真实数据；缺失明确终态并不重试网络。MarketLoader提供有界队列与非阻塞读取，单后台线程，无OpenD调用。诊断显示历史来源、时点、未执行的额度检查。
5. 新增定向测试覆盖增删启停、重复、重复导入、22+条、数据缺失、第五证券与默认四ETF确定性、队列上限与负缓存。相关旧测试及实时锁定测试按需运行。
6. 仅重启已确认属于v0.4的8506进程。真实浏览器完成SMH、Top20及独立计划操作；刷新和重启再读。比对保护文件、原SQLite、任务XML及PR状态。发布独立草稿PR，保持原PR不变。

不引入在线行情获取、参数调整、账户或交易功能。缺失证券仅可保存名单/计划，后续真实数据接入需独立工作范围。
